# DeepGarden 商机调研 Skill

> **本 Skill 属于 DeepGarden 系列**，与 `deepgarden-ipo-research`（DeepGarden 新股研究）、
> `deepgarden-earnings-tracking`（DeepGarden 定期财报跟踪）、`deepgarden-report-deep-read`
> （DeepGarden 公司研报精读）同出 **Deep Garden 出品**。
> **DeepGarden 系列 Skill 知识库由 Deep Garden 出品** —— 欢迎下载、讨论与交流使用心得；
> 后续将持续发布更多商业研究与投资研究相关的 Skill，欢迎关注。

把一次"这个生意 / 项目值不值得做"的判断，拆成可复用、可证伪、可打分的 8 维度系统调研。
本 skill 源于一次真实的"垃圾发电厂炉渣回收"商机调研，已沉淀为通用框架，并通过「行业特色框架适配」
（见 framework.md 末尾）切换到轻资产 / 餐饮等不同赛道变体，避免硬套失真。

---

## ⚠️ 适用边界（重要，请先读）

- **当前版本仅覆盖「中国大陆」行业商机现状调研。** 全部数据源（招投标、上市公司、政策规划、
  工商财务、行业研报）的搜集口径均限定于国内公开市场。涉及境外 / 跨境业务、外币结算、
  他国监管与竞争格局的判断，本模型暂不直接支持，须先完成「国际扩展」升级（见
  `references/international-roadmap.md`）。
- **不参与证券投资咨询。** 若调研对象涉及证券 / 投资，结论仅作信息整理与方法论示范，
  **不构成投资建议**；严禁给出具体个股买卖建议（个人无投顾资质）。涉及"推荐 + 导流金融产品"
  的变现模式须规避。
- 报告须附免责声明：数据来自公开渠道、仅供商机评估参考、关键决策以现场尽调与审计为准。

## 何时使用

- 用户问"XX 行业 / 项目值得做吗""帮我调研 XX 商机""XX 商业模式能不能参与"
- 用户需要一份结构化的行业 + 财务 + 风险 + 打分报告，用于内部决策或对外合作判断
- 朋友 / 渠道介绍了一个项目，用户希望先独立验证"效益好不好"再下注

## 核心交付物

1. 一份 **结构化 HTML 调研报告**（8 维度 + 结论建议 + 行业术语换算章节），模板见 `assets/report-template.html`
2. 一份 **多维度评分表**（8 维加权打分，见 `references/scoring.md`）
3. 一份 **尽调 Checklist**（在报告"结论与行动建议"中给出）
4. 一份 **行业术语与指标换算词表**（与业内人士对话的通用语言，见 `references/glossary.md`）

## 调研框架（步骤 S0–S8 × 评分维度 D1–D8，两套编号别混淆）

完整调研步骤清单与关键红线、反套路提示，见 `references/framework.md`（**调研步骤 S0–S8** = 做事流程）。
评分体系见 `references/scoring.md`（**评分维度 D1–D8** = 评估坐标轴），S→D 映射表在 framework.md 开头。
术语词典与指标换算（含通用采集方法 + 炉渣行业实例 + 向业内人士必问 10 问），见 `references/glossary.md`。

| 步骤 | 内容 | 核心问题 | 典型数据源 |
|---|------|----------|------------|
| S0 | 业务边界界定 | 本次调研的具体生意是什么？相邻业务是什么？ | 产业链研报、企业主营业务描述 |
| S1 | 行业前景与规模 | 市场空间多大、增速、政策驱动、渗透率 | 部委规划、行业协会、研报 |
| S2 | 甲方乙方与竞争格局 | 谁付钱、谁干活、集中度、壁垒；四类主体穷举 | 招投标、股权穿透、年报 |
| S3 | 收入成本与财务模型 | 收益率 / 回收期 / IRR 是否经得起推敲 | 官方备案、上市公司分部数据 |
| S4 | 进入门槛与适配对象 | 资金 / 技术 / 资质 / 关系门槛 vs 自身资源 | 资质目录、项目可研 |
| S5 | 合作模式与风险点 | 特许经营 / 委托 / 分成，权责与退出 | 中标公告、合同条款 |
| S6 | 招投标数据校验 | 用真实中标价反推 / 校验财务模型参数（轻资产 / 餐饮赛道替换为蹲点或上市分部反向校验） | 公共资源交易中心、采招网、同商圈蹲点 |
| S7 | 公开披露主体对标 | 主板 + 新三板 / 北交所 / IPO 在审 / 被并购标的，有无公开数据可印证 | 巨潮、北交所 / 股转系统、招股书、i 问财 |
| S8 | 多维评分与结论 | 按 D1–D8 加权打分，给可 / 慎 / 否结论 | 本 skill 评分卡 |

## 标准工作流

0. **业务边界界定（必须最先做）**：画产业链全景树，用一句话定义"本次调研的具体生意"，列出"相邻但不同"的业务（如地面煤层气抽采销售 ≠ 井下瓦斯发电），建立**业务相关性过滤器**——后续所有对标主体必须先过此关。否则极易把大类赛道（如"煤层气"）直接当调研对象，导致上游卖气企业错配进发电赛道。
   **判定行业类型 → 选框架变体**：在 S0 之后、正式调研前，先按 framework.md「行业特色框架适配」路由表判定赛道类型（重资产 A / 轻资产服务 B / 餐饮实体 E / 平台内容 C / 硬件制造 D），据此切换 S6 校验方式、D4 口径、D7 权重等参数，不硬套默认重资产配置。
1. **先给方向判断**：开宗明义一句话结论（"朋友说的好"是否有真实基础、是否被简化 / 误导），再展开。
1.5 **建术语词表（口径先行）**：填入 `references/glossary.md` 的 6 类通用术语 + 本行业专属词表，
   对齐"口径 / 单位 / 归属"再算账；报告须含"行业术语与指标换算"章节，便于与业内人士用同一语言对话。
2. **并行搜集基础数据**：行业规模 + 政策 + 竞争格局（多路 WebSearch 并行，限定国内口径）。
3. **深挖财务与门槛**：财务模型、上市公司、技术门槛（按需 WebSearch）。
4. **招投标 / 反向校验（关键反套路步骤）**：重资产抓 20+ 真实中标数据；轻资产 / 餐饮替换为上市分部财务 + 监管通报 / 同商圈蹲点反向校验，识别"暴利模型"把甲方收益错算成乙方收入等常见造假手法。
5. **多维打分**：按 `references/scoring.md` 给评分维度 D1–D8 打分，得出综合结论与阈值判定。
6. **输出 HTML 报告**：套用 `assets/report-template.html`，含 8 维内容 + 术语换算 + 评分表 + **模板执行自检**（四道防线是否触发：业务边界界定 / 主体穷举 / 非主板核查 / 相关性过滤）+ 尽调 Checklist + 免责声明（含国内限定提示）。

## 数据源与搜索策略

见 `references/data-sources.md`（含**国内限定声明**与未来国际渠道路线图）。重点：招投标用各省市公共资源交易中心 + 中国政府采购网 + 采招网 + 乙方官网"中标公告"栏目；上市公司用巨潮 / 同花顺 i 问财；企业工商财务用天眼查 / 企查查（注意：非上市公司真实营收利润基本看不到，要靠中标额反推、年报公示的"营业总收入"、财税版报告）。

**拓宽披露渠道（关键方法）**：公开数据不止"已上市主板公司"。凡是**递交过招股书 / 申报材料
（IPO 在审、已问询、已撤回）、新三板挂牌、北交所在审、港交所递表、被并购标的（重组报告书 + 业绩承诺）**
的企业，都披露过成体系的财务与业务数据——这是穿透产业链中小玩家（尤其乙方）"财务黑箱"的最佳渠道。
资料较早的（如 5 年以上）仍可用作结构参考，但必须备注年份与时效性。

## 反套路红线（来自实战教训）

- **命名陷阱**：招标名带"出售 / 销售"≠乙方买渣，必须翻到"费用由谁付、钱往哪流"那一行。
- **资产久期错配**：重资产项目合同只签 3–5 年，但设备折旧 8–10 年。模型必须按服务期加速摊销 + 期末补残值 / 退场现金流，否则 IRR 被严重高估。
- **收益归属错配**：网上高收益模型常把甲方的"填埋节省 / 碳收益"错算成乙方收入。
- **一般固废 vs 危废**：炉渣 = 一般固废，飞灰 = 危废 (HW18)，混淆会导致环保重罚 + 停产。
- **"暴利"信号**：凡是声称"50% 收益率、2 年回本"的模型，优先证伪而非采信。
- **产值 ≠ 利润**：政府 / 媒体宣传的"年产值 XX 亿"是产能 × 售价的宣传口径，未经审计，与"营收"更与"净利"是三回事；引用时必须换算 / 降档处理。
- **渠道别只盯主板**：找不到上市对标 ≠ 没有公开数据；先搜"XX 行业 + 新三板 / 北交所 / 招股书 / 问询 / 重组报告书"，招股书 (申报稿) + 问询回复常常就是一份免费尽调报告。

## 国际扩展路线（未来能力，当前未启用）

用户已明确未来会拓展**国际业务商机**调研。当前模型与信息渠道仅限国内，升级所需的模型变更与
数据源清单已整理在 `references/international-roadmap.md`（币种归一 / FX 风险 / 跨境合规 / 本地竞争情报 /
非中文搜索与社媒 / 各国工商与监管公开库等）。在 roadmap 落地前，请勿将本报告结论直接外推至境外市场。

## 合规与免责

- 若调研对象涉及证券 / 投资，结论仅作信息整理与方法论示范，**不构成投资建议**；
  严禁给出具体个股买卖建议（个人无投顾资质）。涉及"推荐 + 导流金融产品"的变现模式需规避。
- 报告必须附带免责声明：数据来自公开渠道、仅供商机评估参考、关键决策以现场尽调与审计为准。
- **地域范围声明**：本 skill 当前仅支持中国大陆境内的行业商机现状调研；境外 / 跨境扩展见 `references/international-roadmap.md`。

## 输出规范

- 报告用中文、HTML 单文件、含目录、可打印 / 可分享。
- 关键数字标注来源与年份；存疑数据标注"待尽调核实"。
- 结尾给 3 档行动建议（参股 / 合资绑定、自建延伸、轻资产参与）并附尽调 Checklist。

## 与 DeepGarden 系列其他 Skill 的衔接

- 本 Skill 与 `deepgarden-ipo-research`（DeepGarden 新股研究）、`deepgarden-earnings-tracking`
  （DeepGarden 定期财报跟踪）、`deepgarden-report-deep-read`（DeepGarden 公司研报精读）同属
  **DeepGarden 系列**，可单独安装、按需组合。
- **研究链路衔接**：本 skill 是"生意值不值得做"的**上游筛选项**——当一个商机通过本框架、进一步
  想看具体标的是否值得投资时，可移交 `deepgarden-ipo-research` 做新股 / 公司深度研究，上市后由
  `deepgarden-earnings-tracking` 持续跟踪业绩，出现券商深度研报时再用 `deepgarden-report-deep-read`
  做独立复核，形成「商机筛选 → 标的投研 → 业绩跟踪 → 研报复核」的闭环。
