# 国际业务商机扩展路线（International Expansion Roadmap）

> **状态：规划中，当前版本（v1.2.0）未启用。**
> 本文件是 `deepgarden-opportunity-research` 的**未来能力蓝图**，记录将模型从
> 「中国大陆境内商机调研」扩展到「国际 / 跨境业务商机调研」所需的**模型升级点**与
> **信息渠道清单**。在以下能力落地前，请勿将国内口径的结论直接外推至境外市场。

---

## 0. 为什么需要单独规划

国内版模型沉淀于中文一手数据源（招投标、A 股 / 新三板 / 北交所、部委规划、天眼查 / 企查查）。
国际市场的**数据可得性、监管语境、货币与会计口径、竞争格局结构**都不同，直接套用会系统性失真：

- 国内"招投标反推乙方财务"的硬证据链，在多数海外市场不成立（私有公司财务不公开、无统一招采平台）；
- 国内"非主板核查（招股书 / 问询 / 重组报告书）"依赖 A 股 / 港股披露体系，海外对应 SEC EDGAR / 各国工商与监管公开库；
- 币种、增值税 / 销售税、劳动法、特许经营法规差异巨大，财务模型需币种归一与 FX 风险重估。

因此国际扩展不是"多搜几个网站"，而是**模型维度 + 信息渠道 + 合规口径**的同步升级。

## 1. 模型维度升级点（framework.md / scoring.md 待补）

| 现有维度 | 国际扩展须新增 / 重构的要点 |
|---|---|
| S0 业务边界 | 增加**国别 / 法域边界**：同一生意在不同国家可能归属不同监管类别（如"教培"在欧美多为私营合法、在部分市场受限） |
| S1 行业前景 | 增加**全球 vs 区域市场分层**、本地化渗透率、汇率 / 资本管制对需求的影响 |
| S3 财务模型 | 增加**币种归一（统一折算为本币 / USD）**、**FX 波动对收益率的敏感性**、海外税率（增值税 / 销售税 / 预提税）差异 |
| S4 进入门槛 | 增加**外资准入 / 股比限制 / 本地合伙人强制要求**、跨境数据合规（如 GDPR）、认证壁垒（CE / FCC / UL） |
| S5 合作模式 | 增加**跨境合同管辖法域**、IP 归属、汇款与利润汇出限制 |
| S6 校验方式 | 海外无统一招采平台 → 改用 **Crunchbase / PitchBook 融资与营收估算 + 上市公司海外分部 + 本地行业报告 + 实地 / 代理人核验** |
| S7 对标主体 | 从" A 股 / 港股 / 新三板"扩展为 **SEC EDGAR（美）/ 各国交易所 / 被并购数据库 / 独角兽融资库** |
| D7 合规风险 | 权重与口径重构：加入**国别政治风险、制裁 / 出口管制、数据主权、ESG 强制披露** |
| D8 退出通道 | 增加**跨境并购 / 海外上市 / 资产海外处置**的可得性与汇回限制 |

## 2. 信息渠道清单（data-sources.md 待补）

### A. 企业 / 财务穿透（替代国内"非主板核查"）

| 渠道 | 覆盖范围 | 能挖到什么 |
|---|---|---|
| **Crunchbase** | 全球初创 / 成长企业 | 融资轮次、估值、投资方、营收估算、团队 |
| **PitchBook** | 全球 PE/VC / M&A | 交易、估值、财务近似、赛道 map（部分付费） |
| **CB Insights** | 全球独角兽 / 赛道 | 独角兽榜单、行业报告、State of… 系列 |
| **SEC EDGAR** | 美国上市公司 / 发行人 | 10-K / 10-Q / S-1（IPO）完整财报与风险因子 |
| **各国工商注册公开库** | 英（Companies House）、新（ACRA）、港（ICRIS）、澳（ASIC）等 | 注册信息、年报、董事、财报（口径不一） |
| **OpenCorporates** | 全球公司图谱 | 跨法域实控人穿透（免费层有限） |
| **被并购 / 私募交易库** | PitchBook / Mergermarket | 标的估值、对赌、尽调摘要 |

### B. 行业 / 市场体量

| 渠道 | 覆盖 |
|---|---|
| **OECD · World Bank · IMF** | 宏观经济、行业增加值、营商环境 |
| **Statista · Euromonitor** | 付费行业规模与份额（交叉验证用） |
| **各国行业协会 / 政府统计署** | 本地一手规划与产量 |
| **本地咨询 / 四大行业报告** | 区域竞争格局（如要进入某国，优先读该国语言报告） |

### C. 竞争情报 / 舆情

| 渠道 | 说明 |
|---|---|
| **Google 搜索 + 本地搜索引擎**（如 Naver 韩 / Yandex 俄 / Baidu 国际） | 替代国内百度，须用目标国语言检索 |
| **非中文社媒 / 点评**（Google Maps 评分、Trustpilot、Reddit、本地版大众点评） | 替代国内大众点评 / 抖音，做"同商圈反向校验" |
| **本地招聘网站**（LinkedIn、本地猎头站） | 从招聘规模 / 薪酬反推经营状况 |
| **专利 / 商标库**（WIPO、USPTO、EPO、各国 IPO） | 技术壁垒与自由实施（FTO）核查 |

### D. 合规 / 监管

| 渠道 | 说明 |
|---|---|
| **各国监管机构官网**（SEC、FCA、ESMA、各国市场监管） | 牌照、处罚、警示名单 |
| **制裁 / 出口管制清单**（OFAC、EU、UN） | 政治与合规红线 |
| **数据合规框架**（GDPR / CCPA / 各国个保法） | 涉及用户数据的业务必查 |

## 4. 风险提示

- 海外数据源**质量与可得性差异极大**：英美披露充分，但大量新兴市场数据稀薄，须降低结论置信度并显式标注"待本地尽调"；
- **语言与文化壁垒**：用机器翻译读当地语言研报会丢失口径细节，关键结论须本地代理人复核；
- **合规红线更高**：跨境业务涉及制裁、数据主权、外资准入，D7 合规一票否决权重应高于国内版。
