# 数据源与搜索策略

> **⚠️ 地域范围声明（必读）**：本 skill 当前全部数据源与搜集口径**仅限中国大陆**境内公开信息，
> 用于**国内行业商机现状调研**。下列渠道均为国内平台；涉及境外 / 跨境业务、外币结算、他国监管与
> 竞争格局的判断，本模型暂不支持，须先完成「国际扩展」升级（见 `international-roadmap.md`）。

按维度列出可落地的公开数据获取渠道。优先官方/一手，第三方仅作交叉验证。

## 1. 招投标与中标数据（维度 6 核心，最硬证据）

- **中国政府采购网** (ccgp.gov.cn)：政府采购类项目。
- **各省市公共资源交易中心**：省/市级"公共资源交易服务平台"，搜"XX 炉渣 处置/综合利用 中标"。
- **采招网 / 招标采购导航网 / 千里马**：聚合招标公告与中标结果（部分需会员，可用免费摘要）。
- **乙方官网"中标公告"栏目**：如深恒环保、圣元环保等会披露自身中标。
- **中国招标投标公共服务平台** (cebpubservice.com)。

**检索技巧**：用"处置费用 元/吨""综合利用 服务""特许经营"等组合；同一项目抓两次招标价看波动。

## 2. 公开披露主体对标（维度 7）——不要只盯"已上市主板公司"

**⚠️ 强制动作（凡赛道存在乙方 / 服务商 / 非资源方主体，必须执行，不可跳过）：** 一个赛道里能拿到成体系财务/业务数据的，远不止 A 股主板上市公司。凡是**递交过招股书或申报材料的主体**，都会披露 2–3 年的营收、毛利率、成本结构、客户集中度、募投项目等——这往往是穿透"乙方/非上市龙头财务黑箱"的唯一公开渠道，且申报稿+问询回复本身就是一份**免费尽调报告**（尤其适合验证气源/客户/停机等风险）。检索时必须把下面这些渠道**全部覆盖一遍**，并**先跑非主板检索再跑主板**：

| 渠道 | 平台 | 能挖到什么 |
|---|---|---|
| A 股主板/创业板/科创板 | 巨潮网 cninfo.com.cn、同花顺 i 问财 iwencai.com | 年报/半年报分部数据、研报、行业弹性测算 |
| **北交所 / 新三板** | 北交所 bse.cn、股转系统 neeq.com.cn | **在审 IPO 招股书(申报稿)、问询回复、挂牌公司年报**——常能挖到区域龙头、专精特新中小企业的完整账本 |
| **IPO 在审 / 已问询 / 已撤回** | 证监会/交易所 IPO 审核动态、招股书数据库 | 申报稿披露 3 年财务；**已撤回的招股书仍在网上可查**，反而暴露真实经营与被否原因 |
| **港股递表 / A+H** | 港交所披露易 hkexnews.hk（含"申请版本/聆讯后资料集"） | 递表企业的完整招股书；A+H 企业的境外披露口径更细 |
| **被并购 / 重组标的** | 上市公司重大资产重组报告书、业绩承诺公告 | 标的公司被收购时披露的营收/净利/评估值/对赌——非上市公司难得的一手财务 |
| 债券发行人 | 中国货币网、上清所 | 发过债的企业有募集说明书+定期财报 |

**检索话术示例**："XX行业 新三板 挂牌 招股书 营业收入 毛利率"、"XX 北交所 IPO 受理 问询"、"XX 港交所 递表 聆讯"、"XX 收购 重组报告书 业绩承诺"。

**时效备注规则（重要）：** 招股书/申报稿注明"申报稿签署日+财务截止期"；已撤回材料注明"已撤回，数据截至 XX 年"；更早年份(如 5 年前)的数据仅作趋势参考、须标注年份，价格/成本口径可能已失效。**过早的数据备注即可，不必丢弃**——它仍能反映行业演变轨迹。

**长 PDF（招股书 300–800 页）阅读策略：**
1. **优先不下载全文**：先用 WebSearch 搜"公司名 + 招股书 + 关键词(毛利率/客户集中度/募投)"，
   券商研报、问询回复、财经媒体已把关键数据摘出来了，覆盖 80% 需求。
2. **需要读原文时**：Read 工具可直接分页读 PDF（用 offset/limit 按页读）；先读目录页定位
   "财务会计信息""业务与技术""风险因素"三章的页码，只读这几章，不通读。
3. **PDF 转 MD 兜底**：若 PDF 是扫描件或排版混乱，用 Python 转换（managed venv 装
   `pymupdf4llm` 或 `markitdown`，一行命令转 md），转完用 Grep 按关键词定位章节再精读。
4. **问询回复常比招股书更有料**：交易所问询直击痛点（毛利率下滑原因、客户依赖、关联交易），
   篇幅小得多，优先读。

## 3. 企业工商与财务（北流帮等非上市公司）

**关键认知：非上市公司真实营收/净利润基本看不到。**
- 天眼查/企查查/爱企查：仅能看到
  - 工商年报中企业"自行选择公示"的 **资产总额 / 负债总额 / 营业总收入**（很多选"不公示"）；
  - 完整利润表、毛利率、净利率 **不可见**（非上市不强制审计披露）。
- **反推方法**（更重要）：
  - 中标额反推：年处理量 × 中标单价 = 年营收量级。
  - 产能反推：项目设计产能 × 处理费/资源化售价。
  - 企查查"财税版"报告（若企业授权）：开票金额、纳税、上下游 TOP10。
  - 水母报告（免费）：近 3 年纳税/开票/上下游，摸经营稳定性。
- 国家企业信用信息公示系统：年报基础财务碎片（同天眼查口径）。

## 4. 政策与规划（维度 1）

- 发改委、住建部、生态环境部官网："十四五"规划、补短板方案、名录（如 2025 版危废豁免）。
- 地方政府"无废城市"/再生资源规划。

## 5. 行业规模与技术（维度 1/4）

- 中国城市建设研究院、生态环境部固管中心研报。
- 行业协会（中国环保产业协会、再生资源回收利用协会）。
- 学术/技术文章：灰渣处理技术展望、FAST 工艺等（搜"生活垃圾焚烧 炉渣/飞灰"）。

## 6. 通用搜索策略

- 多路 WebSearch 并行：每路一个子问题（规模 / 格局 / 财务 / 中标 / 上市公司）。
- 交叉验证：同一数字至少 2 个独立来源；招投标价优先于自媒体"暴利"文。
- 存疑数据标注"待尽调核实"，不编造。
