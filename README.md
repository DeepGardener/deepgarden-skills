

## DeepGarden 商机调研（deepgarden-opportunity-research）

系统性商机可行性调研框架：以 8 维度（行业 / 格局 / 财务模型 / 门槛 / 合作 / 招投标校验 / 对标 / 评分）
拆解一门生意值不值得做，输出带评分卡与尽调 Checklist 的结构化 HTML 报告。支持重资产 / 轻资产 / 餐饮
等多赛道框架变体。当前数据口径**仅限中国大陆**；国际 / 跨境扩展路线见仓库内 `references/international-roadmap.md`。

- 与 `deepgarden-ipo-research`（新股研究）、`deepgarden-earnings-tracking`（定期财报跟踪）、
  `deepgarden-report-deep-read`（研报精读）同属 DeepGarden 系列，形成
  「商机筛选 → 标的投研 → 业绩跟踪 → 研报复核」闭环。
